# AI Policy

The NEST Simulator is built and maintained by humans. While we acknowledge that AI tools can increase
productivity, we believe in transparency and human creativity and accountability in software development.

## Requirements for Submitting Issues and Pull Requests

   * Human oversight: All changes must be overseen by humans. Fully automated, AI-generated PRs submitted without
     human review are not accepted.

   * Communication: Contributors must actively engage with reviewers throughout the pull request lifecycle. PRs will
     not be merged without direct human participation; unattended submissions and automated agent responses will be
     closed.

   * Accountability: You are responsible for all changes you submit, even if AI-assisted. You must understand and be
     prepared to explain all submitted code.

We reserve the right to close any issue or pull request that does not appear to meet these requirements.

## Requirements for Reviewers of Pull Requests

 * Human evaluation: Reviews must reflect genuine human evaluation. AI may be used as a tool in preparing a review, but reviewers may not delegate code reviews to AI tools or post raw, unverified LLM summaries as reviews.

 * Communication: Feedback must be specific, actionable, and delivered directly by the reviewer. Automated boilerplate
   comments or bot-mediated review threads do not qualify as meaningful review.

 * Accountability: When you approve a PR, you share responsibility for merging that code into the project. Never approve
   contributions based on superficial AI summaries without personally reading and understanding the diff.

 * Contextual diligence: Verify the logic against project architecture, security constraints, and domain edge cases that
   automated tools frequently overlook. Ensure that tests and documentation match the actual behavior of the changes.

Approvals or reviews determined to be automated, unverified, or generated without genuine human assessment will
be dismissed.
